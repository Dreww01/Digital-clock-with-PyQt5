
# Digital Clock Application

A modern digital clock application built using PyQt5 with a sleek black background and white text display. The application features a custom digital font for an authentic digital clock appearance.

## Features

- Real-time digital clock display
- 12-hour format with AM/PM indicator
- Custom digital font (DS-DIGIT.TTF)
- Sleek black background with white text
- Centered display
- Updates every second
- Window size: 500x200 pixels

## Requirements

- Python 3.x
- PyQt5
- DS-DIGIT.TTF font file

## Installation

1. Clone this repository:
```bash
git clone <your-repository-url>
cd Digital-Clock-PyQt5
```

2. Install the required dependencies:
```bash
pip install PyQt5
```

3. Make sure the `DS-DIGIT.TTF` font file is in the same directory as the Python script.

## Usage

1. Run the application:
```bash
python DIGITAL-CLOCK-USING-PYQT5.PY
```

2. The digital clock window will appear, displaying the current time in 12-hour format.
